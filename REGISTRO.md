# Registro · Memória de Trabalho

Decisões e marcos do projeto, do mais recente para o mais antigo.

## 2026-11-01

- **Logo principal:** pente de RAM (a caixa é um módulo de memória, trocadilho com *working memory*), com a linha "PODCAST · TECNOLOGIA & CLASSE". O texto "Módulo DDR-1917" saiu.
- **Logos alternativos:** carimbo, lambe-lambe e estêncil ficam para outros materiais (capa do podcast, adesivos, banners, camisetas). O selo redondo foi descartado; ele continua no histórico do git.
- **Desenho dos logos:** gerados por `scripts/gerar-logos.py`, com o texto enquadrado pelas métricas reais das fontes (Anton, Alfa Slab One, Big Shoulders Stencil Display, Special Elite). A primeira versão esticava as letras e ficou mal enquadrada.
- **Paleta:** vermelho `#C8102E`, preto `#141414`, papel `#F2EBDD`, amarelo `#FFE600`.

## 2026-10-31

- **Projeto criado:** podcast para profissionais de tecnologia de esquerda.
- **Site:** HTML e CSS estáticos no GitHub Pages, sem Jekyll. O endereço vai ser `memoria-de-trabalho.github.io`.
- **GitHub:** o nome `memoria-de-trabalho` estava livre para a organização. Organização não se cria pela API, então isso é feito no navegador.
- **Distribuição (proposta):** Spotify for Creators como hospedagem gratuita, com o RSS levando o áudio para Apple, Amazon, Deezer e YouTube. O vídeo vai direto para o Spotify e o YouTube.
- **Gravação (proposta):** microfone dinâmico, GarageBand para gravar sozinho, Riverside ou Zencastr com convidados, Auphonic para nivelar o áudio.
